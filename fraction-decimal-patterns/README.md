# Fraction & Decimal Patterns

A practice web app for the Year 8 (MYP Year 3) Fraction & Decimal **Criterion B** summative: using what we know about fractions and decimals to investigate patterns.

Open `index.html` in any browser. It needs no build step or server.

- **Investigations**: five guided tasks (terminating vs recurring, ninths and nines, sevenths and the cyclic number 142857, elevenths, halving sums). Each one moves through the Criterion B strands: collect data (B i), describe the pattern as a general rule (B ii), verify it on new cases and justify why it always works (B iii). Tables are checked automatically and rules get keyword feedback plus a model answer.
- **Explore lab**: a fraction → decimal machine with bar, dot and bracket notation, prime factorisation of the denominator, and a step-by-step long-division table that shows where the remainders start to repeat. A table maker generates many cases at once.
- **Quick fire**: random conversion, prediction and pattern-continuation questions with worked solutions.
- **Rubric & write-up**: student-friendly look-fors for the 7–8 band of Criteria B and C, plus a write-up planner (aim → conclusion) that can be copied into a report.

Recurring decimals are typed with brackets around the repeating block, e.g. `0.1(6)` for 0.1666…

Progress, written rules and ticks are saved in the browser's localStorage. `app.html` is the same page without the document wrapper, used for the published Artifact version.
